# FAQ Chatbot для репетиции 🤖

Легкий консольный чат-бот на Python, который отвечает на 5 главных вопросов о предстоящем мероприятии. Ищет ответы по ключевым словам. Поддерживает подключение стороннего ИИ (через прокси) для обработки неизвестных вопросов.

## Что реализовано
* **Поиск по ключевым словам**: RAG не используется, работает быстро и безотказно из файла `faq.txt`.
* **5 тем**: Время, Команды, Треки, Сдача проекта, Призы.
* **Fall-back логика**: Если бот не знает ответ, он пишет «Не знаю» или делегирует вопрос внешней нейросети.
